# Practical 3: Regression assumptions and diagnostics in R

Practical materials for "Data Science for Geographers".

- `Practical_3_Regression_assumptions_diagnostics.ipynb` is the practical notebook.
- `merged_data.csv` is the dataset created at the end of Practical 1.

Keep the notebook and `merged_data.csv` in the same folder. As in Practical 2, the notebook first removes the six datazones with more than 100 retailers per 1000 people.

The data are simulated: every datazone and value is fictional.

The notebook needs `tidyverse` and an R Jupyter kernel.
